# Metagame 2026

Website and ops app for [Metagame](https://metagame.games).

```sh
pnpm install
cp .env.example .env.local  # then fill in what you need
pnpm dev
pnpm check  # typecheck, lint, format, test
```

Conventions are in [AGENTS.md](AGENTS.md); integrations and their env vars are in [.env.example](.env.example).
